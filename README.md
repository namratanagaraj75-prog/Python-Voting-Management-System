ATM Simulation System using Python
A simple console-based ATM simulation project built using Python.
This project demonstrates basic banking operations such as PIN authentication, balance checking, cash withdrawal, deposit functionality, and card blocking after multiple failed PIN attempts.
Features
User authentication using ATM card number and PIN
Balance inquiry
Cash deposit
Cash withdrawal
Input validation using exception handling
Card blocking after 3 incorrect PIN attempts
Menu-driven interface
Technologies Used
Python
Dictionary Data Structure
Loops and Conditional Statements
Exception Handling
